The goal of this Project Challenge is to create a simple website using a basic structure and applying the tags learned during the practical lessons.  

### 📝 Requirements  

**Mandatory tags (covered in class):**  
`<h1>` to `<h6>`, `<p>`, `<mark>`, `<small>`, `<i>`, `<u>`, `<strong>`, `<ol>`, `<ul>`, `<li>`, `<a>`, `<hr>`, `<sub>`, `<sup>`, `<blockquote>`  

**Suggested additional tags (for research and use):**  
`<font>`, `<del>`, `<abbr>`  
> The idea is to research how these tags work, understand their purpose, and apply them to the website content.
